How the four numbers connect

Two divisions, three lines each. Scalar in → scalar out. Vector in → vector out.

Speed

speed = distance ÷ time
WORKED EXAMPLE
speed  = 12.4 m ÷ 4.0 s
= 3.1 m/s
In words

“On average, you covered 3.1 metres of path every second.” No direction — just a rate.

Velocity

velocity = displacement ÷ time
WORKED EXAMPLE
velocity = 7.1 m → 28° NE ÷ 4.0 s
= 1.8 m/s → 28° NE
In words

“On average, you moved 1.8 metres NE every second.” Magnitude AND direction.

The shortcut to remember
Dividing a scalar by time gives a scalar.   Dividing a vector by time gives a vector.  Time itself is just a number — it never adds direction.

Scalar vs Vector — the pattern behind it all

One question unlocks both pairs: does direction matter?

SCALAR

Magnitude only

A number with a unit. No arrow, no compass — just “how much.”

DISTANCE
— — — 12.4 m
“how much path you walked”
SPEED
— — — 3.1 m/s
“how fast you moved”
Cannot be negative. Adds like ordinary numbers: 5 m + 3 m = 8 m.
VECTOR

Magnitude + Direction

A number, a unit, AND a direction. The arrow matters.

DISPLACEMENT
———→ 7.1 m → 28° NE
“start to end, straight line”
VELOCITY
———→ 1.8 m/s → 28° NE
“how fast AND which way”
Adds head-to-tail. 3 m east + 4 m north = 5 m at 53° NE.
THE PATTERN scalar ÷ time = scalar (distance → speed)   ·   vector ÷ time = vector (displacement → velocity)

Question on Speed – Velocity

Q3 · average velocity on a curved path

A particle moves at constant speed v along a semicircular arc of radius R, from A to B. Find the magnitude of its average velocity.

CHOOSE ONE
SOLUTION

time on arc = πR / v  ·  |avg velocity| = displacement ÷ time = 2R ÷ (πR/v) = 2v/π

Solution

1

Path length (the arc)

A semicircle is half a full circumference.

path = ½ × 2πR = πR
2

Time taken

Speed is constant, so time = path ÷ speed.

t = path ÷ v = πR / v
3

Displacement (A → B)

Straight line from start to end = the diameter.

displacement = 2R
4

Average velocity (step 3 ÷ step 2)

|v⃗avg| = 2R ÷ (πR/v)
= 2R × (v / πR)
= 2v / π
THE PICTURE
The pattern — Whenever the path curves, path > displacement, so average speed > average velocity. Equality only happens on a perfectly straight path.

⚬ ARC ANGLE θ · pick one
Try this  Tap 360°: displacement = 0, so |v⃗avg| = 0 even though speed is still 5 m/s. Tap 60°: chord ≈ arc, so velocity ≈ speed. The smaller the arc, the closer they get.
CALCULATION
INPUTS
θ = 90° = π/2 rad
R = 2 m      v = 5 m/s
STEP-BY-STEP
path = Rθ = 2 × π/2 ≈ 3.14 m
t = path / v = 3.14 / 5 ≈ 0.63 s
displacement = 2R·sin(θ/2)
= 2·2·sin(45°) ≈ 2.83 m
AVERAGE VELOCITY
|v⃗avg| = 2.83 / 0.63 ≈ 4.49 m/s
AVERAGE SPEED
avg speed = path / t ≈ 5.00 m/s
